# Habla

A personal Spanish study app: adaptive Learn mode, swipeable flashcards, typed Write mode,
a timed Match game and spaced-repetition Review. Forgiving typing (accents and small typos are
accepted but flagged), pronunciation via the browser's speech engine, and progress saved locally.

```bash
npm install
npm run dev     # http://localhost:3000
npm test        # answer-grading tests
```

Study sets live in `content/sets/*.json` — see `CLAUDE.md` for the format.
